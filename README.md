# 근태 정리기 — 출퇴근 미스터리 해결기

> **쓰기 전에**
> 1. **넣은 파일은 브라우저를 떠나지 않습니다.** 읽기와 계산은 모두 이 페이지 안에서 합니다. F12 → Network 탭을 열어 둔 채 파일을 넣고 정리해 보면, 페이지 파일과 처방(`rules/`)을 불러오는 요청 말고는 밖으로 보내는 요청이 없는 것을 확인할 수 있습니다.
> 2. **파일 안에 근거가 없는 값은 되살리지 못합니다.** 비어 있는 출근시간이나 «28:30» 같은 있을 수 없는 시각은 고치지 않고 `_표시` 칸에 까닭만 적습니다. 샘플 파일을 정답과 대조했을 때 놓친 오류는 0건이었고, 이런 값 4칸은 표시만 했습니다.
> 3. **고치는 방법(처방)은 `rules/<파일 이름>.json`에서 바꿉니다.** 코드(`clean.js`)에는 처방 값이 없고, 처방 파일을 읽어서 실행할 뿐입니다.

출퇴근 근태관리 엑셀을 끌어다 놓으면, 처방대로 정리한 **정리본**과 무엇을 왜 바꿨는지 적은 **바꾼 기록**을 엑셀 파일로 내려줍니다.

## 쓰는 법

1. 정리기 페이지를 엽니다.
2. 근태관리 엑셀(.xlsx · .xls · .csv)을 끌어다 놓습니다. 연습하려면 «샘플 근태 파일 넣기»를 누르세요 (가상 직원 10명, 2026년 9월, 오류가 섞인 파일).
3. 파일 이름에 맞는 처방(`rules/근태관리.json`)과 이유가 나옵니다. 맞는 처방이 없으면 처방 파일(.json)을 직접 골라 올릴 수 있습니다.
4. «규칙대로 정리»를 누릅니다. 행 수 변화 · 지운 행 · 고친 값 · 표시한 행 · «두 번 돌려도 같은 결과»가 나옵니다.
5. «정리본 내려받기» · «바꾼 기록 내려받기»로 저장합니다.
6. (선택) «정답과 대조»: 정답 파일을 내 컴퓨터에서 고르면 일치하는 행과 어긋난 칸, 그 까닭을 보여 줍니다. 정답 파일은 이 사이트에 없습니다.

### 내 컴퓨터에서 열기

`index.html`을 두 번 눌러 열면 브라우저가 처방 파일을 자동으로 읽지 못합니다. 폴더에서 아래를 실행한 뒤 `http://127.0.0.1:8000/`을 여세요.

```
python -m http.server 8000 --bind 127.0.0.1
```

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면 |
| `clean.js` | 처방을 읽어 실행하는 정리 엔진 (처방 값 없음) |
| `rules/근태관리.json` | 처방: 무엇을 고치고 무엇을 표시만 할지, 그리고 그 이유 |
| `data/근태관리.xlsx` | 지어낸 연습용 근태 파일 (실제 개인정보 없음) |
| `lib/` | SheetJS 0.20.3 (엑셀 읽기·쓰기) — Apache License 2.0, `lib/SHEETJS-LICENSE.txt` |

## 처방 고치기

`rules/근태관리.json`의 `prescriptions` 하나가 처방 하나입니다.

- `action`: `fix`(고침) · `flag`(표시만) · `delete`(지움) · `keep`(그대로)
- `why`: 그렇게 정한 이유 (바꾼 기록에 그대로 적힘)
- `do`: 정리기가 읽는 실행 정보 (종류와 기준값)

처방을 바꾼 뒤에는 샘플로 정리해 보고 «두 번 돌려도 같은 결과»가 «예»인지 확인하세요.
